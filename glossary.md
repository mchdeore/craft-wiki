# Glossary

| Word | What it means |
|---|---|
| About | a few facts about an object, read from its content, shown in lists and used in filters |
| Admin | a role with every right on every object |
| Agent | the name of the job in which Sprout answers |
| Assign | to name who should see to an object; the library takes it and lists it in that person's inbox, and the screens do not offer it |
| Bin | where an object goes before it is removed; it leaves lists and searches, and can be taken out again |
| Call | one of the eight ways into the library: pull, history, push, find, run, squash, remove, sweep |
| Change | what one version did to an object: the pieces, who, when and why |
| Citation | a link in an answer from Sprout to the field, and the version of it, that the answer rests on |
| Commit | to make a draft into one version, with a note |
| Content | the thing an object holds, in the shape its kind declares |
| Copy | an object made from another, which remembers what it came from and can be merged back; also called a fork |
| Draft | what a person has typed and not committed, kept in their own browser |
| Edge | a relation between two objects in a space, drawn as a line on its map |
| Equation | a script tied to a table that fills one column from others |
| Everyone | a role that every person who can sign in holds |
| Fingerprint | a short text worked out from bytes, the same only for the same bytes |
| History | the changes of an object, oldest to newest |
| Image | a packed copy of a program and all it needs, built once and run anywhere |
| Inbox | the space that shows each person their notices and what is assigned to them |
| Job | a request that takes time, kept in a queue: an equation, a notebook run, an answer from Sprout |
| Kind | what sort of object it is: text, table, notebook, space and so on |
| Launcher | the service on a host that makes a machine for one job and destroys it |
| Level | how much someone may do with an object: read, organise, edit or owner |
| Library | all the objects, their changes and their jobs |
| Machine | a small virtual machine that runs one job |
| Merge | to bring the changes of a copy into its original, or the other way, as one version |
| Meta | what people say about an object: title, owner, access, tags, date, links |
| Notebook | cells of code and cells of words, in order |
| Notice | a job that tells you that something you watch has changed, or that something you own was put in the bin, something you wrote in was squashed, or something shared with you was removed |
| Object | one thing in the library, with an id, a kind and a version |
| Owner | the one person who answers for an object and may share it |
| Panel | a list at the side of the screen, such as Files or Notices |
| Piece | a part of an object with a path of its own: a paragraph, a cell, a message |
| Proposal | a change Sprout has in mind, which lands only if a person saves it |
| Refusal | the library's answer when it will not do something, in plain words |
| Restore | to bring an older version's content back, as a new version |
| Role | a name several people hold, which can be given access |
| Session | the time between signing in and being signed out, in one browser |
| Skill | saved instructions, with steps if it has them |
| Space | a map of objects; a space can hold another space |
| Sprout | the assistant in the screens; it reads as its asker and proposes changes |
| Squash | to make an object's early changes into one |
| Sweep | to delete bytes that no version names |
| Table | columns and rows in one object |
| Tag | a word put on an object, to filter by |
| Vector | what an object means, as numbers, for search by meaning |
| Version | one state of an object; every change makes the next |
| View | the screen that opens one kind of object |
| Watch | to ask to be told when an object changes |
| Worker | the program that takes jobs from the queue and works them out |
| Workspace | what a person has open and their own copies; it follows them to any browser |
