# Roadmap

What CRAFT does not do yet. The other pages say what it does now.

## Deferred

Put off, or not decided yet.

| What | Now |
|---|---|
| Running a skill's steps as a workflow, with a screen to build and follow one | a skill keeps its steps as text |
| Schedules that queue jobs, as the person who last changed them | the kind is designed; nothing acts on it |
| Email in and out | the kind is designed; nothing reads or sends one |
| A vector for each section of a long object | one vector stands for a whole object, made from its first part |
| Keeping a notebook's variables alive for a short time between runs | each run starts fresh |
| A nightly check that replays a sample of objects | each read of a past version checks the copy it starts from |

## Vision

- A small group keeps what it knows in one place, and can always say where a statement came from.
- Anything a person can do by hand they can ask of Sprout, through the same calls, with the same rights.
- Work that repeats becomes a workflow: steps anyone can read, each a job that leaves a record and can be run again.
- Nothing is lost: every state of every object can be read back.
- It stays light enough to run whole on one laptop, and moves to any cluster by a copy.
